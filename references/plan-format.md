# plan.json 형식

좌표는 모두 **평면도 이미지 픽셀**(x 오른쪽, y 아래). `walls.png` 격자 숫자가 픽셀이다.

| 키 | 뜻 | 예 |
|---|---|---|
| `name` | 사이트 제목 | `"84㎡ A타입"` |
| `image` | 평면도 파일(walls 단계가 채움) | |
| `scale` | 축척. 셋 중 하나 | `{"bboxWidthM": 11.4}` · `{"bboxHeightM": 8.6}` · `{"a": [330, 63], "b": [2232, 63], "m": 11.4}` |
| `scaleConfirmed` | (예전 이름) 아래 `areaConfirmed` 와 같다 | `true` |
| `areaConfirmed` · `areaNote` | 방 면적이 표기와 10% 넘게 달라도 진행(도면 그림이 자기 치수와 다를 때만). 메모는 마지막 요약에 "면적 확인 필요"와 함께 남는다. 면적 기준: 5% 이내 통과 · 5~10% 진행하고 보고 · 10% 넘으면 멈춤 | `true`, `"침실1 세로 치수가 그림과 다름"` |
| `wallHeight` | 천장 높이(m) | `2.3`(아파트 기본) |
| `wallColor` | 벽 칠 색(기본 흰색 `#FAFAF7`) | `"#F2EEE8"` |
| `floorLevel` | 몇 층인가(창밖 땅 높이를 정한다, 기본 2) | `5` |
| `corridor` | `false` = 단독주택: 현관 밖에 아파트 계단실을 짓지 않는다(기본 true) | `false` |
| `furnished` | `true` = 가구까지 넣는다(`tour.py make … --furnished` 와 같다). 기본값은 구조만 — 붙박이 설비(조리대·신발장·변기·세면대·욕조·샤워부스)만 남긴다 | `true` |
| `walls.remove` | 벽이 아닌 조각 번호(walls.png) | `[0, 6, 7, 90]` |
| `walls.add` | 빠진 벽 `{a, b, tpx?}`(두께 px, 없으면 중간값) | `[{"a": [700, 500], "b": [700, 800]}]` |
| `walls.arcs` | 곡선 벽(둥근 발코니·원형 벽) `{a, b, via, tpx?, type?}`: 양 끝 `a`·`b`와 호에서 가장 튀어나온 점 `via`(모두 벽 두께 가운데 줄 px). `type`은 `glass`(발코니 바깥면 기본) / `wall`(그 밖 기본). 곡선을 따라 직선 조각으로 잡힌 벽(납작한 상자 모양)은 `walls.remove`로 빼고, 현 위에 생기는 틈은 자동으로 버린다 | `[{"a": [119, 183], "b": [119, 322], "via": [81, 253], "tpx": 9}]` |
| `arches` | 트임(`open`)을 반원 아치로 지을 틈 번호 | `["g5", "g8"]` |
| `style` | 마감: `floor`(`"porcelain"` = 욕실 빼고 큰 타일) · `floors`(방 종류별 `wood`/`porcelain`/`tile`) · `woodGrain`(마루 결 강조) · `bathWall`(`"porcelain"`) · `doors`(`"white"`) · `exposure`(노출 배율, 흰 마감이 많으면 0.84) · `ambient`(고른 빛 배율, 낮추면 그림자가 산다) | `{"floor": "porcelain", "floors": {"living": "wood", "bedroom": "wood"}, "doors": "white", "exposure": 0.84, "ambient": 0.82}` |
| `style.tex` | 표면 재질 사진(이름 = `assets/tex/<이름>.jpg`): `wall`(벽·천장·칠한 면) · `wood`(마루) · `porcelain`(큰 타일, 줄눈 포함) · `fabric`(쿠션·담요·코드 소파) · `rug`(러그 결) · `backsplash`(싱크 뒤 벽). 없으면 기존 재질 그대로 | `{"wall": "limewash", "wood": "oakwide", "porcelain": "porcelainstone", "fabric": "boucle", "rug": "wool", "backsplash": "zellige"}` |
| `navAnd` | 전후 비교용: 같은 집 '전' 장면의 scene.json(상대 경로). 두 장면 모두에서 걸을 수 있는 칸만 쓴다 | `"../<이름>.work/scene.json"` |
| `openings` | 틈 번호 → 종류 | `{"g7": "door", "g22": "slide", "g14": "none"}` |
| `openingsAdd` | 자동으로 못 잡은 틈 `{a, b, type}` | `[{"a": [640, 625], "b": [1270, 625], "type": "slide"}]` |
| `sills` | 창턱 높이(m) 바꾸기 | `{"g5": 0.4}` |
| `widths` | 문 폭(m) 바꾸기. 문(`door`)은 기본으로 안쪽 0.8m·현관 0.9m까지 옆 같은 줄 벽을 잘라 넓힌다(직각 벽 쪽은 못 넓힘). `0`이면 넓히지 않음 | `{"g15": 0.75, "g11": 1.0}` |
| `swings` | 문짝 열리는 쪽 강제(1 / -1). 기본: 현관문 바깥 · 방문 방 안 · 다른 문을 막으면 벽에 붙임 | `{"g8": -1}` |
| `hinges` | 경첩 끝 강제(`a` / `b`) | `{"g8": "b"}` |
| `doorOpen` | 문 열린 각도(85 기본 / 175 = 벽에 붙임) | `{"g9": 175}` |
| `clearance` | 걷는 길과 벽·문틀·가구 사이 여유(m): `wall` 0.35 · `door` 0.25 · `furniture` 0.3 | `{"wall": 0.3}` |
| `rooms` | 방 목록 `{name, type, at, area?, floor?}` | 아래 |
| `furniture` | 가구 목록 `{type, at, rot, size?, ...}` | 아래 |
| `start` | 출발점 px(없으면 현관 가운데) | `[718, 690]` |
| `tour` | 투어 순서(방 이름). 없으면 현관 → 거실 → 주방 → 침실 → 드레스룸 → 욕실 → 발코니 | |

## 틈 종류
- `door` 문(높이 2.1m 인방 + 열린 문짝) · `window` 창(창턱 0.9m, 위 2.2m) · `slide` 바닥까지 큰 유리 + 창살(거실–발코니) · `open` 트임(인방만, 유리·창살 없음 — 거실↔주방처럼 그냥 지나다니는 곳) · `none` 틈 아님(지움)
- 도면에 흰 띠·얇은 선으로 그려진 실내 칸막이도 목업·사진에 유리가 안 보이면 `open`으로 둔다.
- 기본값: 바깥에 닿으면 `window`, 안쪽 1.3m 이하면 `door`, 2.2m 이하면 `open`, 더 길면 버림(벽 끝에서 방을 가로지른 가짜 틈). 최소 폭은 벽 두께의 2.2배(0.3m 이상) — 도식 도면은 문이 0.4m쯤으로 그려진다.
- 남은 틈은 종류와 상관없이 모두 방 경계가 된다(`none`만 경계 아님).

## 방 종류(`type`)
`living` 거실 · `kitchen` 주방/식당 · `bedroom` 침실 · `bath` 욕실(타일 벽·바닥) · `entry` 현관(타일, 한 단 낮음) · `balcony` 발코니(타일) · `dress` 드레스룸 · `hall` 복도 · `office` 서재 · `utility` 다용도실(타일) · `outdoor` 테라스

- `at` = 방 이름 글자 위치(방 안 아무 점이면 된다). 벽 없이 이어진 공간(거실+주방)은 점마다 가까운 쪽으로 나눈다.
- `area` = 도면 표기 면적(대조용, 화면에도 이 값을 보여 준다).
- `floor` = `"wood"` / `"tile"`로 바닥 강제.
- 이름 점이 없는 빈 공간은 0.6㎡ 이상이면 `복도`, 그보다 작으면 `수납`(붙박이 수납칸)으로 자동 추가해 바닥·천장만 깐다(목록·투어에는 안 넣음).

## 가구(`type`, 기본 크기 m = 폭 × 깊이 × 높이)
| 종류 | 크기 | 모델 | 비고 |
|---|---|---|---|
| `sofa` | 2.1×0.9×0.8 | 생성 3D | |
| `armchair` | 0.85×0.85 | 생성 3D | |
| `tv` | 1.8×0.45×1.25 | 생성 3D(TV장+TV) | |
| `bed` / `bed-single` | 1.6×2.1 / 1.1×2.0 | 생성 3D | 앞 = 발치 쪽 |
| `nightstand` | 0.45×0.4×0.5 | 코드 + 스탠드 | |
| `wardrobe` | 1.8×0.6×2.2 | 코드(원목) | `"color": "white"` |
| `dresser` | 1.2×0.45×0.8 | 코드 | |
| `desk` + `chair` | 1.2×0.6 / 0.5×0.5 | 코드 / 3D | 의자 rot = 책상 쪽 |
| `dining` | 1.6×0.9 | 3D 식탁 + 의자 | `"chairs": 4` 긴 변 양쪽 |
| `table` | 1.2×0.7 | 3D | |
| `counter` | 2.4×0.6×0.9 | 코드 | `"sink"`, `"cooktop"`, `"upper"`(상부장·벽 타일) |
| `island` | 1.8×0.9 | 코드 | |
| `fridge` | 0.9×0.75×1.85 | 코드 | |
| `washer` | 0.6×0.65×0.85 | 코드 | |
| `shoe` | 1.0×0.4×2.2 | 코드(흰색) | 현관 신발장 |
| `toilet` | 0.4×0.68 | 생성 3D | |
| `vanity` | 0.8×0.5 | 생성 3D | |
| `bathtub` | 1.6×0.75 | 생성 3D | |
| `shower` | 0.9×0.9 | 코드(유리) | |
| `dressing-table` | 1.2×0.4×1.36 | 생성 3D | 서랍 3단 + 선반 + 아치 거울 화장대 |
| `plant` · `lamp` | 0.5×0.5 · 0.35×0.35 | 3D | |
| `rug` | 2.0×1.4 | 코드 | 걷기 막지 않음 |

- `rot` = **앞면이 향하는 방향**(도): `0` 아래 · `90` 오른쪽 · `180` 위 · `270` 왼쪽. 소파·의자 앞 = 앉은 사람이 보는 쪽, 침대 앞 = 발치, 장·조리대·TV 앞 = 문이 열리는 쪽.
- `size` = `[폭, 깊이]` m. 조리대·붙박이장은 길이를 꼭 적는다.
- 벽에 붙는 가구(침대·장·조리대·TV·변기·세면대·욕조·소파 등)는 뒤쪽 1m 안의 벽에 자동으로 붙고, 벽에 박혀 있으면 앞으로 빠진다(`"snap": false`로 끔).

## build가 스스로 고치는 것(출력에 한 줄씩 나온다)
- 벽 두께 → 0.10~0.30m.
- 가구·식탁 의자 → 벽·문 앞·건물 밖·다른 가구와 겹치면 ±0.4m 안에서 옮김(벽에 붙는 가구는 벽을 따라 옆으로만, 걸리면 폭을 최대 30% 줄임). 그래도 겹치는 의자는 뺌.
- 돌아가는 길 → 방 사이 길이 가구 없는 집보다 1.35배 + 1m 넘게 길면 그 길을 가장 줄여 주는 `dining`·`table`을 뺌. 조리대·장이 원인이면 경고만 하므로 자리를 직접 옮긴다.
- 좁은 방 → 끊긴 방은 그 방과 문 둘레만 여유를 줄여 길을 잇는다.

## 가구 항목 추가 키(인테리어 교체용)

| 키 | 뜻 |
|---|---|
| `props` | 가구 위 생활 소품 세트: `books`(선반) · `cushions`(소파) · `bedding`(침대) · `dining`(식탁) · `kitchen`(싱크·화구 조리대) · `pantry`(하부장) · `office`(책상: 노트북·노트·스탠드) · `bath`(세면대: 거울·비누) · `reading`(책 두 권) · `tray`(쟁반·초·머그) |
| `color` | 가구 색(흰 3D 모델에 색 입힘). `shell-chair`는 몸판만 그 색, 다리는 검정. `desk`는 `"white"` |
| `variant` | `sofa: "soft"`(코드로 짓는 직물 소파) · `vanity: "box"`(코드 세면대) · `rug: "round"` · `wall-arch: "rect"`(벽 아래쪽만 칠한 면) |
| `pattern`·`accent` | 러그 무늬(`border`·`stripe`·`check`)와 무늬 색 |
| `y0`·`image` | 벽 그림(`poster`)의 바닥에서 높이와 그림 파일(`assets/art/…`) |

새 가구 종류: `side-lamp`(빨간 사이드테이블+버섯 조명) · `shell-chair` · `office-chair` · `lounge`(부클레 라운지 의자) · `stool`(부클레 스툴) · `round-table`(받침 하나 둥근 식탁, `h`로 사이드테이블도) · `shelf`/`wave-shelf`(칸 책장) · `poster`(벽 그림) · `wall-arch`(벽에 칠한 아치·사각 색 면) · `pendant`(천장 조명, `y0` = 갓 아래 높이).
